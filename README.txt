DREB FOOTBALL — FINAL UPGRADE PACK

شنو تزاد فهاد النسخة؟
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- مباريات اليوم، المباشرة، القادمة، المنتهية، والمفضلة.
- البحث والتصفية حسب البطولة والترتيب حسب الوقت أو البطولة.
- نتائج ووقت المغرب، اختيار التاريخ، تحميل المزيد، وتحديث تلقائي كل 90 ثانية.
- إمكانية تثبيت الموقع كتطبيق PWA من المتصفح، مع واجهة تعمل دون اتصال للصفحات التي سبق تحميلها.
- خيار إشعارات تغيّر النتيجة أو حالة المباراة أثناء بقاء الصفحة مفتوحة. الإشعارات اختيارية وتحتاج موافقة المستخدم؛ ماشي إشعارات خادمة من السيرفر والصفحة مسدودة.
- معالجة أوضح لأخطاء API ومفتاح API يبقى سرياً في Netlify.

طريقة النشر:
1) فك الضغط.
2) فـ GitHub repo DREB-Football-Final بدّل الملفات القديمة بالملفات اللي فهاد الحزمة مع الحفاظ على المسارات:
   index.html
   styles.css
   app.js
   manifest.webmanifest
   sw.js
   icons/icon.svg
   icons/icon-192.png
   icons/icon-512.png
   netlify.toml
   netlify/functions/matches.mjs
3) تأكد أن Netlify ما زال فيه Environment Variable باسم FOOTBALL_DATA_API_KEY. ما تحطش المفتاح فالكود أو فـ GitHub وما ترسلو حتى لشي حد.
4) Commit changes وانتظر Deploy فـ Netlify يكمل بنجاح.
5) اختبر الرابط /.netlify/functions/matches?days=7، ثم افتح الموقع من الهاتف وحدّث الصفحة.
6) فـ Chrome على Android: القائمة ⋮ ثم Install app أو Add to Home screen، حسب اللي كيبان عندك.

حدود مهمة:
- المباريات والتغطية كيعتمدوا على football-data.org وخطة API ديالك؛ ما كنضمنوش توفر كل الدوريات أو كل أحداث المباريات.
- ما زدناش جدول ترتيب أو إحصائيات وهمية؛ خاص endpoint ومعلومات مسموح بها من مزود البيانات باش نضيفوها بدقة.
- إشعارات تغيّر النتائج كتخدم والصفحة مفتوحة فقط. الإشعارات فخلفية كاملة أو والصفحة مسدودة كتحتاج Push service وتهيئة إضافية.
- خَلّي الموقع القديم كما هو؛ هاد الملفات مخصصة للمشروع الجديد DREB-Football-Final.
